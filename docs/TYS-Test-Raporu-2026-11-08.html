3. Kritik bulgular (P0)

P0-1 · Create tarafında oda çakışması engellenmiyor

  • Aynı oda + örtüşen tarihler için ikinci POST /reservation/create 200 döndü.
  • availableRooms 101’i listeden düşürüyor; create bu kontrolü uygulamıyor.
  • Öneri: Update’teki müsaitlik doğrulamasını create’e taşıyın.

P0-2 · Geçersiz tarih aralığı kabul ediliyor

  • checkOut < checkIn ile create başarılı oldu (DB’de id=7 kanıtlandı, sonra silindi).
  • Öneri: BE’de zorunlu tarih kuralı + 400.

P0-3 · Tenant izolasyonu eksik

  • Company1 JWT ile GET /room/by-company/2 → 3 oda sızdı.
  • Öneri: Path’teki companyId JWT ile eşleşmezse 403; mümkünse endpoint’i kaldırıp sadece JWT scoped liste kullanın.

4. Orta öncelik

  • P1 Login hata yanıtı HTTP 401 olmalı (şu an 200 + success:false).
  • P1 Sidebar navigasyonda içerik gecikmesi / URL-içerik uyumsuzluğu.
  • P1 /payment/ (trailing slash) 401 — Security path matcher.
  • P2 Legend typo “Rezarvasyonlu”; form varsayılan checkout tarihi.
